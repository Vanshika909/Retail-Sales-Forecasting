# Retail Sales Forecasting Dashboard

## Project Overview

This project aims to analyze retail sales data, identify business trends, and forecast future sales using data analytics and machine learning techniques. The project provides actionable business insights through exploratory data analysis and interactive dashboards.

## Objectives

* Analyze historical retail sales data.
* Identify sales trends and customer purchasing patterns.
* Perform exploratory data analysis (EDA).
* Forecast future sales using time series forecasting techniques.
* Create interactive dashboards for business decision-making.

## Tech Stack

* Matplotlib

* Prophet
* Power BI
